# Linuxの絶対パスと相対パスとは？パスの指定方法を初心者向けに解説

Linuxでファイルやディレクトリを操作するときに欠かせないのが、**パス（Path）**という考え方です。

Linuxコマンドを使っていると、

```bash
cd /home/user01/Documents
```

や、

```bash
cd Documents
```

といった指定をよく目にします。

どちらもディレクトリの場所を指定していますが、指定方法が異なります。

今回はLinuxの基本となる**絶対パスと相対パス**について、実際にコマンドを使いながら学んでいきます。

## パスとは？

パスとは、簡単にいうと、

**ファイルやディレクトリがどこにあるのかを表す住所**

です。

Linuxでは、ファイルやディレクトリが階層構造で管理されています。

たとえば、次のような構成があるとします。

```text
/
├── etc
├── home
│   ├── user01
│   │   ├── Documents
│   │   ├── Downloads
│   │   └── linux-practice
│   └── user02
├── tmp
└── var
    └── log
```

`Documents`ディレクトリの場所は、

```text
/home/user01/Documents
```

と表せます。

Linuxでは、このようにディレクトリ名を`/`で区切って場所を表現します。

## まず覚えたい3つのディレクトリ

絶対パスと相対パスを理解する前に、Linuxでよく登場する3つの言葉を確認しておきましょう。

### ルートディレクトリ

Linuxのディレクトリ構造の一番上にあるのが**ルートディレクトリ（Root Directory）**です。

```text
/
```

で表します。

```text
/
├── etc
├── home
├── tmp
├── usr
└── var
```

Linuxでは、すべてのファイルやディレクトリがこの`/`を起点とした階層構造の中にあります。

Windowsの`C:\`などとは構造の考え方が少し異なります。

### カレントディレクトリ

**カレントディレクトリ（Current Directory）**とは、現在自分がいるディレクトリです。

現在地は`pwd`コマンドで確認できます。

```bash
pwd
```

たとえば、

```text
/home/user01
```

と表示された場合、現在のカレントディレクトリは`/home/user01`です。

Linuxで相対パスを利用するときは、この**カレントディレクトリが基準**になります。

### ホームディレクトリ

**ホームディレクトリ（Home Directory）**とは、ユーザーごとに用意される作業場所です。

たとえば、

```text
/home/user01
/home/user02
```

のような形です。

`user01`でログインしている場合、

```text
/home/user01
```

がホームディレクトリになる構成が一般的です。

ホームディレクトリは`~`を使って表すこともできます。

```text
~
```

## 絶対パスとは？

**絶対パス（Absolute Path）**とは、ルートディレクトリ`/`を起点として、目的のファイルやディレクトリまでの場所をすべて指定する方法です。

たとえば、

```text
/home/user01/Documents
```

は絶対パスです。

階層構造で見ると、

```text
/
└── home
    └── user01
        └── Documents
```

となります。

コマンドでは、

```bash
cd /home/user01/Documents
```

と指定できます。

絶対パスの特徴は、**現在どこにいても同じ場所を指定できること**です。

たとえば現在地が、

```text
/var/log
```

だったとしても、

```bash
cd /home/user01/Documents
```

と入力すれば`Documents`へ移動できます。

### 絶対パスの見分け方

基本的には、

**先頭が`/`から始まっている**

ことに注目します。

```text
/home/user01/Documents
/etc/hosts
/var/log
/tmp
```

これらはすべてルートディレクトリから場所を指定しているため、絶対パスです。

## 相対パスとは？

**相対パス（Relative Path）**とは、現在いるカレントディレクトリを基準として場所を指定する方法です。

たとえば現在地が、

```text
/home/user01
```

だったとします。

その中に、

```text
/home/user01
├── Documents
├── Downloads
└── linux-practice
```

というディレクトリがある場合、

```bash
cd Documents
```

だけで`Documents`へ移動できます。

絶対パスなら、

```bash
cd /home/user01/Documents
```

です。

相対パスなら、

```bash
cd Documents
```

です。

どちらも同じ場所へ移動しています。

違うのは**どこを基準として場所を指定しているか**です。

```text
絶対パス
↓
ルートディレクトリ / が基準


相対パス
↓
現在いるディレクトリが基準
```

## 絶対パスと相対パスを比較してみよう

現在地が、

```text
/home/user01
```

だったとします。

`Documents`へ移動する場合、

### 絶対パス

```bash
cd /home/user01/Documents
```

### 相対パス

```bash
cd Documents
```

となります。

次に現在地が、

```text
/tmp
```

だった場合を考えてみます。

絶対パスなら、

```bash
cd /home/user01/Documents
```

で移動できます。

しかし、

```bash
cd Documents
```

では、`/tmp`の中にある`Documents`を探すことになります。

つまり相対パスは、**現在地によって意味が変わる**という特徴があります。

## 「.」は現在地を表す

Linuxでは、

```text
.
```

が**現在のディレクトリ**を表します。

たとえば現在地が、

```text
/home/user01/linux-practice
```

で、その中に、

```text
sample.sh
```

がある場合、

```text
./sample.sh
```

は、

```text
現在いるディレクトリにあるsample.sh
```

という意味になります。

```text
/home/user01/linux-practice
│
├── sample.sh
│
└── .
    ↑
  現在地
```

Linuxでは今後、プログラムやスクリプトを実行するときなどに`./`という表記を目にすることがあります。

## 「..」は1つ上を表す

```text
..
```

は**1つ上のディレクトリ**を表します。

たとえば現在地が、

```text
/home/user01/Documents
```

だったとします。

```bash
cd ..
```

を実行すると、

```text
/home/user01
```

へ移動します。

イメージすると、

```text
/home/user01
     ↑
     │
     │ cd ..
     │
/home/user01/Documents
```

となります。

2階層上へ移動したい場合は、

```bash
cd ../..
```

と指定できます。

たとえば、

```text
/home/user01/Documents
```

から実行すると、

```text
/home
```

へ移動します。

## 「~」はホームディレクトリを表す

`~`は、現在ログインしているユーザーの**ホームディレクトリ**を表すためによく利用されます。

たとえばホームディレクトリが、

```text
/home/user01
```

の場合、

```bash
cd ~
```

でホームディレクトリへ移動できます。

また、

```bash
cd ~/Documents
```

と指定すると、

```text
/home/user01/Documents
```

へ移動できます。

そのため、

```bash
cd /home/user01/Documents
```

とすべて入力しなくても、

```bash
cd ~/Documents
```

と短く指定できます。

## 「/」と「~」は別物

初心者のうちは`/`と`~`を混同しやすいので注意しましょう。

```text
/
```

は**Linux全体の一番上にあるルートディレクトリ**です。

一方、

```text
~
```

は**現在ログインしているユーザーのホームディレクトリ**を表します。

たとえば、

```text
/
└── home
    └── user01
        ↑
        ~
```

という関係になります。

## パスはcd以外でも使う

パスはディレクトリを移動する`cd`だけで使うものではありません。

たとえばファイルをコピーするときにも使います。

```bash
cp sample.txt /tmp/
```

これは、

```text
sample.txt
   ↓
 /tmp/
```

へコピーするという意味です。

相対パスを使って、

```bash
cp sample.txt ../
```

とすれば、現在地から1つ上のディレクトリへコピーできます。

ファイルを移動するときも同じです。

```bash
mv sample.txt /tmp/
```

ファイルの内容を確認するときにも、

```bash
cat /etc/hosts
```

のようにパスを指定します。

つまり、Linuxのさまざまなコマンドでパスの考え方を利用します。

## よく使うパス表現まとめ

| 表記 | 意味 |
|---|---|
| `/` | ルートディレクトリ |
| `.` | 現在のディレクトリ |
| `..` | 1つ上のディレクトリ |
| `~` | 現在のユーザーのホームディレクトリ |
| `/home/user01` | 絶対パスの例 |
| `Documents/sample.txt` | 相対パスの例 |
| `../sample.txt` | 1つ上を基準にした相対パス |
| `~/Documents` | ホームディレクトリを利用した指定 |

## 実際に操作してみよう

最後に、実際にパスを使って移動してみましょう。

まずホームディレクトリへ移動します。

```bash
cd ~
```

現在地を確認します。

```bash
pwd
```

練習用のディレクトリを作ります。

```bash
mkdir -p linux-practice/path-test
```

相対パスを使って移動します。

```bash
cd linux-practice/path-test
```

現在地を確認します。

```bash
pwd
```

次に1つ上へ移動します。

```bash
cd ..
```

もう一度確認します。

```bash
pwd
```

今度は絶対パスを使って`/tmp`へ移動します。

```bash
cd /tmp
```

確認します。

```bash
pwd
```

最後にホームディレクトリへ戻ります。

```bash
cd ~
```

この練習では、

```text
~
↓
linux-practice/path-test
↓
..
↓
/tmp
↓
~
```

と移動しています。

実際に`pwd`を実行しながら操作すると、パスの仕組みを理解しやすくなります。

## まとめ

- パスはファイルやディレクトリの場所を表す
- Linuxのディレクトリ構造は`/`を起点としている
- `/`はルートディレクトリ
- カレントディレクトリは現在いるディレクトリ
- ホームディレクトリはユーザーごとに用意される作業場所
- 絶対パスは`/`を基準に場所を指定する
- 相対パスは現在地を基準に場所を指定する
- `.`は現在のディレクトリ
- `..`は1つ上のディレクトリ
- `~`は現在のユーザーのホームディレクトリを表すためによく使われる
- `pwd`を使えば現在地を確認できる
- パスは`cd`だけでなく`cp`、`mv`、`cat`などさまざまなコマンドで利用する

絶対パスと相対パスは、Linuxを操作するときに何度も使う基本的な考え方です。

まずは、

**「絶対パスは `/` から、相対パスは現在地から」**

という違いを押さえておきましょう。
