# Linux基本コマンド集｜初心者が最初に覚えたいコマンドを実際に使ってみよう

Linuxでは、マウスで画面を操作するだけでなく、**コマンドを入力してコンピューターを操作する**ことがよくあります。

Linuxサーバーを扱うなら、コマンド操作は避けて通れません。

とはいえ、最初から大量のコマンドを暗記する必要はありません。

今回は、Linux初心者が最初に覚えておきたい基本的なコマンドを、実際の操作例と一緒に見ていきます。

## はじめに

Linuxでは、文字を入力してコンピューターを操作する**CLI（Command Line Interface）**がよく利用されます。

たとえば、

```bash
ls
```

と入力すると、現在いる場所にあるファイルやディレクトリを確認できます。

最初は黒い画面に文字だけが表示されていて難しそうに感じるかもしれません。

しかし、基本的な操作は、

```text
現在地を確認する
↓
ファイルを見る
↓
ディレクトリを移動する
↓
ファイルを作る
↓
コピー・移動する
↓
不要になったら削除する
```

という流れで考えると分かりやすくなります。

## 1. まず覚えたい基本コマンド

最初に、この記事で扱うコマンドを確認しておきましょう。

| コマンド | 主な用途 |
|---|---|
| `pwd` | 現在いるディレクトリを確認 |
| `ls` | ファイルやディレクトリを表示 |
| `cd` | ディレクトリを移動 |
| `mkdir` | ディレクトリを作成 |
| `touch` | 空のファイルを作成 |
| `cp` | ファイルやディレクトリをコピー |
| `mv` | ファイルの移動・名前変更 |
| `rm` | ファイルやディレクトリを削除 |
| `cat` | ファイルの内容を表示 |
| `less` | ファイルの内容をページ単位で表示 |
| `head` | ファイルの先頭部分を表示 |
| `tail` | ファイルの末尾部分を表示 |
| `clear` | 画面を整理 |
| `history` | 過去に実行したコマンドを確認 |

まずは、このあたりから慣れていけば十分です。

## 2. pwd：現在いる場所を確認する

`pwd`は、現在自分がいるディレクトリを確認するコマンドです。

```bash
pwd
```

実行結果の例です。

```text
/home/user01
```

これは、

```text
/
└── home
    └── user01
        ↑
      現在地
```

という意味です。

Linuxでは、現在どのディレクトリにいるかによってコマンドの結果が変わることがあります。

そのため、

> **迷ったらまずpwd**

と覚えておくと便利です。

## 3. ls：ファイルやディレクトリを確認する

現在いるディレクトリに何があるのか確認するには`ls`を使います。

```bash
ls
```

たとえば、

```text
Documents
Downloads
minecraft
sample.txt
```

のように表示されます。

### 詳しい情報を表示する

`-l`オプションを付けると、より詳しい情報を確認できます。

```bash
ls -l
```

例：

```text
-rw-r--r-- 1 user01 user01 1200 Sep 16 20:00 sample.txt
```

ここには、

- パーミッション
- 所有者
- 所有グループ
- ファイルサイズ
- 更新日時
- ファイル名

などが表示されています。

所有者・グループ・パーミッションについては、別の記事で詳しく解説します。

### 隠しファイルも表示する

Linuxでは、`.`から始まるファイルは通常の`ls`では表示されません。

```bash
ls -a
```

とすると、隠しファイルも表示できます。

さらに、

```bash
ls -la
```

とすれば、**隠しファイルを含めて詳細表示**できます。

`ls -la`はLinuxを操作すると頻繁に使う形の一つです。

## 4. cd：ディレクトリを移動する

ディレクトリを移動するときは`cd`を使います。

```bash
cd Documents
```

これで`Documents`ディレクトリへ移動できます。

移動できたか確認してみましょう。

```bash
pwd
```

```text
/home/user01/Documents
```

### 1つ上のディレクトリへ戻る

```bash
cd ..
```

`..`は、1つ上の階層を表します。

```text
/home/user01/Documents
          ↓ cd ..
/home/user01
```

### ホームディレクトリへ移動する

```bash
cd ~
```

または単純に、

```bash
cd
```

でもホームディレクトリへ移動できます。

`~`は現在のユーザーのホームディレクトリを表すためによく利用されます。

## 5. 絶対パスと相対パス

Linuxでファイルやディレクトリを指定するときには、**パス**を利用します。

たとえば、

```bash
cd /var/log
```

のように`/`から場所を指定する方法を**絶対パス**と呼びます。

一方、

```bash
cd Documents
```

のように現在いるディレクトリを基準として指定する方法を**相対パス**と呼びます。

```text
絶対パス
→ / から場所を指定する

相対パス
→ 現在地から場所を指定する
```

パスはLinuxを操作するうえで非常に重要なので、別の記事で詳しく解説します。

## 6. mkdir：ディレクトリを作る

新しいディレクトリを作るには`mkdir`を使います。

```bash
mkdir linux-practice
```

確認してみます。

```bash
ls
```

```text
linux-practice
```

これで新しいディレクトリが作成されました。

移動してみましょう。

```bash
cd linux-practice
```

## 7. touch：ファイルを作る

練習用の空ファイルを作ってみます。

```bash
touch sample.txt
```

確認します。

```bash
ls
```

```text
sample.txt
```

`touch`には本来ファイルのタイムスタンプを変更する役割がありますが、指定したファイルが存在しない場合には空のファイルが作成されるため、ファイル作成にもよく利用されます。

## 8. cat：ファイルの内容を確認する

テキストファイルの内容を確認するときによく利用するのが`cat`です。

```bash
cat sample.txt
```

たとえばファイルに、

```text
Hello Linux!
```

と書かれていれば、

```bash
cat sample.txt
```

の実行結果として、

```text
Hello Linux!
```

と表示されます。

短い設定ファイルなどを確認するときにも便利です。

## 9. less：長いファイルを確認する

`cat`はファイル全体を一気に表示します。

そのため、非常に長いログファイルなどでは見づらくなることがあります。

そこで利用できるのが`less`です。

```bash
less sample.txt
```

`less`では画面をスクロールしながら内容を確認できます。

終了するときは、

```text
q
```

を押します。

サーバーではログや設定ファイルを確認することが多いため、覚えておくと便利です。

## 10. headとtail：先頭・末尾だけ確認する

ファイルの先頭部分を確認するには`head`を使います。

```bash
head sample.txt
```

反対に、末尾部分を確認するには`tail`を使います。

```bash
tail sample.txt
```

特にログを確認するときには`tail`が便利です。

```bash
tail -f app.log
```

とすると、ファイルに追加される内容を継続的に表示できます。

サーバーでアプリケーションのログを確認するときなどによく利用されます。

終了するときは通常、`Ctrl + C`を押します。

## 11. cp：ファイルをコピーする

ファイルをコピーするときは`cp`を使います。

```bash
cp sample.txt sample-copy.txt
```

確認してみます。

```bash
ls
```

```text
sample-copy.txt
sample.txt
```

元の`sample.txt`を残したまま、新しく`sample-copy.txt`が作成されています。

### ディレクトリをコピーする

ディレクトリをコピーするときには`-r`を利用します。

```bash
cp -r directory1 directory2
```

`-r`はディレクトリの中身を含めて再帰的にコピーするために利用します。

## 12. mv：移動・名前変更

`mv`には主に2つの使い方があります。

### ファイルを移動する

```bash
mv sample.txt Documents/
```

これで`sample.txt`が`Documents`へ移動します。

### ファイル名を変更する

```bash
mv sample.txt linux.txt
```

これは、

```text
sample.txt
↓
linux.txt
```

という名前変更になります。

Linuxでは、ファイルの移動と名前変更に同じ`mv`コマンドを利用します。

## 13. rm：ファイルを削除する

ファイルを削除するときは`rm`を使います。

```bash
rm sample.txt
```

### ディレクトリを削除する

ディレクトリとその中身を削除するときは、

```bash
rm -r linux-practice
```

のように`-r`を利用します。

### rmは特に注意する

`rm`で削除したファイルは、GUIの「ゴミ箱」のように簡単に元へ戻せるとは限りません。

特に`-r`や`-f`を組み合わせた削除は強力です。

意味を理解しないまま実行すると、大切なファイルやディレクトリを削除してしまう可能性があります。

初心者のうちは、

> **rmを実行する前に、削除対象を必ず確認する**

という習慣をつけておきましょう。

## 14. clear：画面をきれいにする

ターミナルが文字でいっぱいになったときは、

```bash
clear
```

を実行します。

画面を整理して作業を続けられます。

## 15. history：過去のコマンドを確認する

以前実行したコマンドを確認したいときには、

```bash
history
```

を利用できます。

例：

```text
1  pwd
2  ls
3  cd Documents
4  mkdir linux-practice
5  cd linux-practice
6  touch sample.txt
```

「あのコマンドどう書いたっけ？」

となったときにも便利です。

また、キーボードの上下キーを使って過去に入力したコマンドを呼び出せる場合もあります。

## 16. コマンドのオプションとは？

Linuxコマンドでは、

```bash
ls
```

のような基本コマンドに、追加の指定を付けることがあります。

たとえば、

```bash
ls -l
```

です。

この`-l`のような指定を**オプション**と呼びます。

```text
ls -l
│   │
│   └── オプション
└────── コマンド
```

さらに、

```bash
ls -la /var/log
```

のような指定もできます。

```text
ls       -la       /var/log
│         │            │
コマンド  オプション    対象
```

この形を理解しておくと、Linuxコマンドがかなり読みやすくなります。

## 17. コマンドの使い方が分からないとき

Linuxにはコマンドのマニュアルを確認する`man`があります。

たとえば`ls`について確認するなら、

```bash
man ls
```

とします。

終了するときは`q`を押します。

また、コマンドによっては、

```bash
ls --help
```

のように`--help`を指定することで簡単な使い方を確認できます。

すべてのオプションを暗記する必要はありません。

**必要になったときに調べられることもLinuxでは大切です。**

## 18. 実際に操作してみよう

ここまでのコマンドを使って簡単な練習をしてみましょう。

まず現在地を確認します。

```bash
pwd
```

ホームディレクトリへ移動します。

```bash
cd ~
```

練習用ディレクトリを作ります。

```bash
mkdir linux-practice
```

移動します。

```bash
cd linux-practice
```

ファイルを作ります。

```bash
touch honey.txt
```

確認します。

```bash
ls -l
```

コピーします。

```bash
cp honey.txt honey-copy.txt
```

ファイル名を変更します。

```bash
mv honey-copy.txt honey-backup.txt
```

確認します。

```bash
ls -l
```

最後に不要なファイルを削除します。

```bash
rm honey-backup.txt
```

もう一度確認します。

```bash
ls -l
```

この流れだけでも、

```text
pwd
 ↓
cd
 ↓
mkdir
 ↓
touch
 ↓
ls
 ↓
cp
 ↓
mv
 ↓
rm
```

というLinuxの基本的なファイル操作を一通り体験できます。

## 🍯 はちみつメモ

> **Linuxコマンドは全部暗記しなくても大丈夫！**
>
> まずは`pwd`、`ls`、`cd`を使って「今どこにいて、そこに何があるのか」を確認できるようになりましょう。
>
> そこから`mkdir`、`cp`、`mv`、`rm`などを少しずつ覚えていけばOKです。

## まとめ

今回はLinuxを操作するための基本的なコマンドを学びました。

### この記事で覚えること

- `pwd`で現在地を確認する
- `ls`でファイルやディレクトリを確認する
- `cd`でディレクトリを移動する
- `mkdir`と`touch`でディレクトリやファイルを作る
- `cat`や`less`でファイルの内容を確認する
- `cp`でコピー、`mv`で移動や名前変更をする
- `rm`でファイルを削除するときは十分注意する
- オプションを使うことでコマンドの動作を変更できる
- 分からないコマンドは`man`や`--help`で確認できる

Linuxコマンドは、実際にターミナルへ入力してみるのが一番の練習になります。

まずは練習用のディレクトリを作り、その中でファイルの作成・コピー・移動・削除を試してみましょう。
