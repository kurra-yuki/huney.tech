# Amazon EC2とは？AWSの仮想サーバーを初心者向けに解説

Amazon EC2は **Amazon Elastic Compute Cloud** の略で、AWS上でコンピューティング能力を利用できるサービスです。

初心者向けには、まず**AWS上で仮想サーバーを作って利用できる代表的なサービス**と理解すると分かりやすいです。

## EC2インスタンスとは？

EC2で起動した仮想的なサーバーを**EC2インスタンス**と呼びます。

```text
AWS
 └─ Amazon EC2
      └─ EC2インスタンス
           ├─ CPU
           ├─ メモリ
           ├─ OS
           └─ ネットワーク
```

## インスタンスタイプ

EC2では用途に応じてCPUやメモリなどの構成が異なる**インスタンスタイプ**を選択できます。

Webサーバー、開発環境、計算処理など、ワークロードに合わせて選びます。

## AMIとは？

EC2インスタンスを起動するときには**AMI（Amazon Machine Image）**を利用します。

AMIにはOSなど、インスタンスを起動するために必要な情報が含まれています。

Amazon LinuxやUbuntuなどを利用することもできます。

## EBSとは？

EC2でよく利用されるストレージが**Amazon EBS（Elastic Block Store）**です。

EC2インスタンスに接続して、OSやデータなどを保存するブロックストレージとして利用できます。

EC2とEBSは別サービスとして考えるのがポイントです。

## セキュリティグループ

EC2などへの通信を制御する重要な仕組みが**セキュリティグループ**です。

許可する受信・送信トラフィックをルールとして設定します。

インターネットへ公開する場合でも、必要な通信だけを許可することが重要です。

## EC2とVPC

EC2インスタンスは通常、Amazon VPC内のサブネットに配置します。

```text
VPC
 └─ Subnet
      └─ EC2
```

ネットワーク編で学んだIPアドレス、サブネット、ルーティングなどの知識がAWSでもつながります。

## EC2はサーバーレス？

EC2では利用者がOSやインスタンスなどを管理する必要があります。

そのため、AWS Lambdaのようなサーバーレスサービスとは管理する範囲が異なります。

## 🍯 はちみつメモ

> **Amazon EC2 = AWS上で仮想サーバーなどのコンピューティング能力を利用できるサービス**

## まとめ

- EC2はAWSの代表的なコンピューティングサービス
- 起動した仮想サーバーをEC2インスタンスと呼ぶ
- インスタンスタイプでCPU・メモリなどを選ぶ
- AMIを利用してインスタンスを起動する
- EBSをストレージとして利用できる
- セキュリティグループで通信を制御する
- EC2は通常VPC内に配置される
