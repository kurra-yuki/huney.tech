# クラウドとは？オンプレミスとの違いを初心者向けに解説

クラウドコンピューティングとは、サーバー、ストレージ、データベースなどのITリソースを、必要に応じてネットワーク経由で利用する考え方です。

従来は自社でサーバーなどを購入して設置する方法が一般的でした。このように自分たちで設備を保有・管理する形は**オンプレミス**と呼ばれます。

```text
オンプレミス
会社
 └─ 自分たちでサーバーを購入・設置・管理

クラウド
会社
 └─ ネットワーク経由で必要なITリソースを利用
```

## クラウドの特徴

クラウドでは、必要なリソースを比較的短時間で用意し、需要に応じて増減できます。サービスによって異なりますが、利用量に応じて料金を支払う従量課金も代表的な特徴です。

## オンプレミスとの違い

| 項目 | オンプレミス | クラウド |
|---|---|---|
| 設備 | 自分たちで保有 | クラウド事業者の基盤を利用 |
| 導入 | 調達・設置が必要 | 比較的すばやく利用開始できる |
| 拡張 | 機器追加などが必要 | リソースを柔軟に変更しやすい |
| 費用 | 初期投資が大きくなりやすい | 従量課金など複数の料金モデル |

クラウドが常に安いという意味ではありません。使い方によってはコストが大きくなるため、設計や監視が重要です。

## クラウドで何が使える？

代表的には、

- コンピューティング
- ストレージ
- データベース
- ネットワーク
- セキュリティ
- AI・機械学習

など、多くのIT機能をサービスとして利用できます。

## パブリック・プライベート・ハイブリッド

クラウドには複数の利用モデルがあります。

**パブリッククラウド**は、クラウド事業者が提供する共有基盤上のリソースを利用するモデルです。AWSは代表的なパブリッククラウドです。

**プライベートクラウド**は、特定の組織向けに利用されるクラウド環境です。

**ハイブリッドクラウド**は、オンプレミスやプライベート環境とパブリッククラウドなどを組み合わせる考え方です。

- 従量課金が代表的な料金モデルのひとつ
- AWSは代表的なクラウドサービス
