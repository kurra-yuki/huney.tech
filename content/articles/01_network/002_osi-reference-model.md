# OSI参照モデルとは？7つの層を初心者向けにやさしく解説

OSI参照モデルは、ネットワーク通信を理解するための代表的な考え方です。

大切なのは7層を丸暗記することより、**通信の仕事を役割ごとに分けて考えるモデル**だと理解することです。

## OSI参照モデルとは？

OSI参照モデルは、ネットワーク通信に必要な機能を**7つの階層（レイヤー）に分けて整理したモデル**です。

OSIは「Open Systems Interconnection」の略です。

## なぜ層に分けるの？

通信には、信号を送る、同じネットワーク内で届ける、別のネットワークへ届ける、通信を制御するなど、多くの仕事があります。

これらを役割ごとに分けることで、仕組みを理解しやすくなります。

## 7つの層

| 層 | 名前 | 大まかな役割 |
|---|---|---|
| 第7層 | アプリケーション層 | アプリケーション向けの通信サービス |
| 第6層 | プレゼンテーション層 | データ表現など |
| 第5層 | セッション層 | 通信のやり取りの管理 |
| 第4層 | トランスポート層 | アプリケーション間の通信制御 |
| 第3層 | ネットワーク層 | ネットワーク間の配送 |
| 第2層 | データリンク層 | リンク上でのデータ転送 |
| 第1層 | 物理層 | 電気・光・電波などによる伝送 |

## 第1層：物理層

電気信号、光、電波などを使ってビットを伝送するための層です。

## 第2層：データリンク層

EthernetやMACアドレスなどが関係します。L2スイッチもこの層と深く関係します。

## 第3層：ネットワーク層

IP、IPアドレス、ルーター、ルーティングなどが関係する層です。

## 第4層：トランスポート層

TCPやUDPなどが関係します。アプリケーション間でデータを届けるための制御を担当します。

## 第5〜7層

上位層では、通信セッション、データ表現、アプリケーションが利用する通信機能などを扱います。

HTTPやDNSなど、ユーザーが利用するサービスに近いプロトコルも登場します。

## OSI参照モデルと実際の通信

現在のインターネットでは**TCP/IP**が広く利用されています。

それでもOSI参照モデルは、通信を整理したり障害を切り分けたりするときの共通言語として非常に便利です。

「L2スイッチ」「L3スイッチ」「L7ロードバランサー」のLもLayerを意味します。

## まとめ

- OSI参照モデルは通信機能を7層に分けたモデル
- 層ごとに役割が異なる
- L2、L3などネットワーク機器の説明にも使われる
- 実際のインターネットではTCP/IPが広く利用されている
- 通信の理解やトラブルの切り分けに役立つ
