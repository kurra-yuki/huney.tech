# DHCPとは？IPアドレスを自動設定する仕組みを初心者向けに解説

スマートフォンを自宅のWi-Fiにつなぐと、多くの場合すぐにインターネットを利用できます。

毎回IPアドレスを手入力していないのに、なぜ通信できるのでしょうか。

その裏側でよく利用されているのが**DHCP**です。

## DHCPとは？

DHCPは **Dynamic Host Configuration Protocol** の略です。

ネットワークへ接続する端末に、**IPアドレスなどのネットワーク設定を自動的に配布するためのプロトコル**です。

## 何を設定してくれる？

DHCPでは、環境に応じて次のような情報を端末へ提供できます。

- IPアドレス
- サブネットマスク
- デフォルトゲートウェイ
- DNSサーバー

これらを毎回手作業で設定するのは大変です。

DHCPを利用すると、端末をネットワークへ接続したときに必要な設定を自動化できます。

## DHCPサーバーとDHCPクライアント

設定情報を提供する側を**DHCPサーバー**、設定を受け取る端末を**DHCPクライアント**と呼びます。

家庭では、家庭用ルーターがDHCPサーバーの役割を持っていることがよくあります。

```text
       家庭用ルーター
       DHCPサーバー
       /     |      \
      /      |       \
    PC     スマホ    ゲーム機
        DHCPクライアント
```

## IPアドレスは貸し出される

DHCPでは、IPアドレスを一定期間端末へ**貸し出す（リースする）**考え方があります。

利用可能なアドレスの範囲を用意し、その中からクライアントへアドレスを割り当てます。

リースには有効期間があり、クライアントは必要に応じて更新します。

## DORAとは？

DHCPによるIPv4設定の基本的な流れとして、よく**DORA**が紹介されます。

### 1. Discover

クライアントが利用できるDHCPサーバーを探します。

### 2. Offer

DHCPサーバーが、利用可能なIPアドレスなどを提案します。

### 3. Request

クライアントが、提示された設定を利用したいことを要求します。

### 4. Acknowledge

DHCPサーバーが要求を確認し、割り当てを確定します。

頭文字を取ると、

```text
D = Discover
O = Offer
R = Request
A = Acknowledge
```

です。

## DHCPサーバーが別ネットワークにある場合

DHCPの最初の通信ではブロードキャストが利用されます。

ルーターは通常、ブロードキャストを別ネットワークへそのまま転送しません。

そこで、DHCPサーバーが別のネットワークにある場合には**DHCPリレー**を利用する構成があります。

DHCPリレーがクライアントとDHCPサーバーの間を中継します。

## DHCPを使わない場合

サーバーやネットワーク機器など、IPアドレスを固定して運用したい機器では手動設定を利用することがあります。

また、DHCP側で特定のクライアントに決まったアドレスを割り当てるよう構成する方法もあります。

DHCPと固定設定は、用途に応じて使い分けます。

## まとめ

- DHCPはDynamic Host Configuration Protocolの略
- IPアドレスなどのネットワーク設定を自動配布できる
- DHCPサーバーとDHCPクライアントがある
- IPアドレスは一定期間リースされる
- 基本的な流れはDiscover、Offer、Request、Acknowledge
- 別ネットワークのDHCPサーバーを利用するためにDHCPリレーを使う場合がある
