# TCP/IPとは？インターネット通信の基本を初心者向けに解説

TCP/IPは、現在のインターネットを理解するうえで欠かせない考え方です。

## TCP/IPとは？

TCP/IPとは、インターネットなどで広く利用されている**通信プロトコル群の総称**です。

名前にはTCPとIPが入っていますが、TCPとIPだけを意味するわけではありません。HTTPやDNS、UDPなど、さまざまなプロトコルが関係します。

## TCPとIPの違い

### IP

IP（Internet Protocol）は、主に**データを宛先まで届けるための仕組み**を担当します。

### TCP

TCP（Transmission Control Protocol）は、アプリケーション間で**信頼性のあるデータ通信**を行うための仕組みを提供します。

かなり単純化すると、

- IP = どこへ届けるか
- TCP = きちんと届けるための制御

とイメージできます。

## TCP/IPモデル

一般的には次の4階層で説明されます。

| 層 | 主な役割 | 代表例 |
|---|---|---|
| アプリケーション層 | アプリケーション向け通信 | HTTP、DNSなど |
| トランスポート層 | アプリケーション間の通信 | TCP、UDP |
| インターネット層 | ネットワーク間の配送 | IP |
| ネットワークインターフェース層 | 実際のネットワーク上での転送 | Ethernetなど |

## OSI参照モデルとの関係

OSI参照モデルは7層、TCP/IPモデルは一般的に4層で説明されます。

完全に同じものではありませんが、通信機能を役割ごとに階層化して考える点は共通しています。

## Webサイトを見る場合

Webアクセスでも複数のプロトコルが協力します。

```text
HTTP / HTTPS
     ↓
    TCP
     ↓
     IP
     ↓
Ethernet / Wi-Fi など
```

実際にはDNSやTLSなど、さらに多くの仕組みが関係します。

## TCP以外にUDPもある

トランスポート層ではUDPも利用されます。

TCPは再送や順序制御などを備え、信頼性を重視します。UDPはそれらを標準では行わない、よりシンプルな方式です。

用途に応じて使い分けられます。

- TCP/IPモデルは一般的に4層で説明される
- HTTPやDNSなど多くのプロトコルが協力して通信している
