# Amazon Aurora

## 正式名称

**Amazon Aurora**

## 一言でいうと

**AWSがクラウド向けに構築したリレーショナルデータベース**

## 初心者向け説明

Amazon RDSで利用できるデータベースエンジンのひとつです。MySQLおよびPostgreSQLとの互換性を持つエディションがあります。

- クラウド / AWSを学ぶうえで重要な用語
