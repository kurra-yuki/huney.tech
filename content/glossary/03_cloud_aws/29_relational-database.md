# リレーショナルデータベース

## 正式名称

**Relational Database**

## 一言でいうと

**データをテーブルなどで管理し、データ同士の関係を扱うデータベース**

## 初心者向け説明

行と列を持つテーブルを中心にデータを管理し、SQLを使って検索・更新するシステムが代表的です。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「データをテーブルなどで管理し、データ同士の関係を扱うデータベース」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
