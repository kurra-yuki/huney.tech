# Amazon EBS

## 正式名称

**Amazon Elastic Block Store**

## 一言でいうと

**EC2などで利用できるブロックストレージサービス**

## 初心者向け説明

EC2インスタンスに接続し、OSやデータを保存するディスクのような用途で利用できます。S3のオブジェクトストレージとは性質が異なります。

- クラウド / AWSを学ぶうえで重要な用語
