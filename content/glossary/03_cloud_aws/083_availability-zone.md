# アベイラビリティーゾーン

## 正式名称

**Availability Zone (AZ)**

## 一言でいうと

**AWSリージョン内にある独立したインフラストラクチャ拠点**

## 初心者向け説明

1つのAWSリージョンは複数のAZから構成されます。複数AZを利用することで、障害に備えた高可用性構成を設計できます。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「AWSリージョン内にある独立したインフラストラクチャ拠点」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
