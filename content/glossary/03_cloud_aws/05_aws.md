# AWS

## 正式名称

**Amazon Web Services**

## 一言でいうと

**Amazonが提供する幅広いクラウドサービス群**

## 初心者向け説明

コンピューティング、ストレージ、データベース、ネットワークなど、多数のITサービスをクラウドとして提供しています。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「Amazonが提供する幅広いクラウドサービス群」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
