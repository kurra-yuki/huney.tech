# EC2インスタンス

## 正式名称

**EC2 Instance**

## 一言でいうと

**Amazon EC2で起動する仮想的なコンピューティング環境**

## 初心者向け説明

CPUやメモリなどの構成をインスタンスタイプから選択し、AMIなどを使って起動します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「Amazon EC2で起動する仮想的なコンピューティング環境」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
