# パブリッククラウド

## 正式名称

**Public Cloud**

## 一言でいうと

**クラウド事業者が提供するクラウド基盤を利用する形**

## 初心者向け説明

AWSなどのクラウド事業者が提供する基盤上で、利用者が必要なITリソースを利用するクラウドモデルです。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「クラウド事業者が提供するクラウド基盤を利用する形」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
