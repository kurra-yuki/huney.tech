# Amazon RDS

## 正式名称

**Amazon Relational Database Service**

## 一言でいうと

**リレーショナルデータベースの構築・運用を支援するAWSのマネージドサービス**

## 初心者向け説明

MySQL、PostgreSQL、Amazon Auroraなど複数のデータベースエンジンを利用できます。インフラや一部のDB運用作業をAWSに任せられます。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「リレーショナルデータベースの構築・運用を支援するAWSのマネージドサービス」と覚えればOK
