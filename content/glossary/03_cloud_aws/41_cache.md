# キャッシュ

## 正式名称

**Cache**

## 一言でいうと

**よく使うデータを一時的に保持し、再利用しやすくする仕組み**

## 初心者向け説明

CloudFrontではオリジンから取得したコンテンツをエッジ側にキャッシュし、条件が合えば次回以降はオリジンへ問い合わせずに返せます。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「よく使うデータを一時的に保持し、再利用しやすくする仕組み」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
