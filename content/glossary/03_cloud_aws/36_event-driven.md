# イベント駆動

## 正式名称

**Event-Driven**

## 一言でいうと

**何らかのイベントをきっかけに処理を実行する設計**

## 初心者向け説明

S3へのファイル保存などの出来事をきっかけにLambda関数を実行する、といった構成があります。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「何らかのイベントをきっかけに処理を実行する設計」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
