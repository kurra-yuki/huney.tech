# エッジロケーション

## 正式名称

**Edge Location**

## 一言でいうと

**CloudFrontなどがコンテンツ配信に利用するAWSの拠点**

## 初心者向け説明

利用者に近い場所からキャッシュされたコンテンツを配信することで、低遅延なアクセスを支援します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「CloudFrontなどがコンテンツ配信に利用するAWSの拠点」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
