# ハイブリッドクラウド

## 正式名称

**Hybrid Cloud**

## 一言でいうと

**オンプレミスなどとパブリッククラウドを組み合わせて利用する考え方**

## 初心者向け説明

既存のオンプレミス環境とクラウド環境など、複数の環境を組み合わせてシステムを構成します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「オンプレミスなどとパブリッククラウドを組み合わせて利用する考え方」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
