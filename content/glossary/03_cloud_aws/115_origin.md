# オリジン

## 正式名称

**Origin**

## 一言でいうと

**CDNがコンテンツを取得する元のサーバーやサービス**

## 初心者向け説明

CloudFrontではAmazon S3やApplication Load Balancerなどをオリジンとして利用できます。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「CDNがコンテンツを取得する元のサーバーやサービス」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
