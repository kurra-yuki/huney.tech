# AMI

## 正式名称

**Amazon Machine Image**

## 一言でいうと

**EC2インスタンスを起動するために必要な情報を含むイメージ**

## 初心者向け説明

OSやソフトウェアなど、EC2インスタンスを起動するためのテンプレートとして利用されます。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「EC2インスタンスを起動するために必要な情報を含むイメージ」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
