# プライベートサブネット

## 正式名称

**Private Subnet**

## 一言でいうと

**インターネットゲートウェイへの直接のルートを持たないサブネット**

## 初心者向け説明

データベースなどをインターネットから直接アクセスさせたくない場合などに利用されます。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「インターネットゲートウェイへの直接のルートを持たないサブネット」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
