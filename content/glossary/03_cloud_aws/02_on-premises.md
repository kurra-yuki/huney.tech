# オンプレミス

## 正式名称

**On-Premises**

## 一言でいうと

**サーバーなどのIT設備を自分たちで保有・管理する形**

## 初心者向け説明

組織が自社設備としてサーバーやネットワーク機器などを用意し、構築・運用する形です。クラウドと比較するときによく登場します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「サーバーなどのIT設備を自分たちで保有・管理する形」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
