# クラウド

## 正式名称

**Cloud Computing**

## 一言でいうと

**サーバーやストレージなどのITリソースを必要に応じてネットワーク経由で利用する考え方**

## 初心者向け説明

自分で物理サーバーなどを用意する代わりに、クラウド事業者が提供するITリソースを必要に応じて利用します。AWSは代表的なパブリッククラウドです。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「サーバーやストレージなどのITリソースを必要に応じてネットワーク経由で利用する考え方」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
