# Amazon S3

## 正式名称

**Amazon Simple Storage Service**

## 一言でいうと

**データをオブジェクトとして保存するAWSのストレージサービス**

## 初心者向け説明

画像、動画、ログ、バックアップなどをオブジェクトとしてバケットへ保存します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「データをオブジェクトとして保存するAWSのストレージサービス」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
