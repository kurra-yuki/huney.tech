# S3バケット

## 正式名称

**S3 Bucket**

## 一言でいうと

**Amazon S3でオブジェクトを保存するためのコンテナ**

## 初心者向け説明

S3ではまずバケットを作成し、その中にオブジェクトを保存します。バケットにはアクセス制御なども設定します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「Amazon S3でオブジェクトを保存するためのコンテナ」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
