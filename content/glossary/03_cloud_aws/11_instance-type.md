# インスタンスタイプ

## 正式名称

**Instance Type**

## 一言でいうと

**EC2インスタンスのCPUやメモリなどの構成を定めた種類**

## 初心者向け説明

用途に合わせてさまざまなインスタンスタイプから選択します。必要以上に大きなものを選ぶとコスト増加につながるため、適切な選定が重要です。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「EC2インスタンスのCPUやメモリなどの構成を定めた種類」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
