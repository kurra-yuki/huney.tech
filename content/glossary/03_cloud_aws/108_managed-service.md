# マネージドサービス

## 正式名称

**Managed Service**

## 一言でいうと

**基盤の管理や運用作業の一部をクラウド事業者に任せられるサービス**

## 初心者向け説明

利用者がすべてを自分で管理するのではなく、サービスによってOSやインフラ、バックアップなどの一部をAWS側が管理します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「基盤の管理や運用作業の一部をクラウド事業者に任せられるサービス」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
