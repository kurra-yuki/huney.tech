# ネットワークACL

## 正式名称

**Network Access Control List**

## 一言でいうと

**VPCのサブネット単位で通信を制御する仕組み**

## 初心者向け説明

サブネットへ出入りする通信をルールで制御します。セキュリティグループとは適用単位や動作が異なり、ネットワークACLはステートレスです。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「VPCのサブネット単位で通信を制御する仕組み」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
