# Amazon CloudFront

## 正式名称

**Amazon CloudFront**

## 一言でいうと

**世界各地のエッジネットワークを利用してコンテンツを配信するAWSのCDN**

## 初心者向け説明

オリジンから取得したコンテンツをエッジロケーションなどから利用者へ配信し、低遅延な配信を支援します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「世界各地のエッジネットワークを利用してコンテンツを配信するAWSのCDN」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
