# S3ストレージクラス

## 正式名称

**S3 Storage Class**

## 一言でいうと

**アクセス頻度や保存目的などに応じて選ぶS3の保存クラス**

## 初心者向け説明

頻繁に利用するデータや長期保管するデータなど、用途に合わせて複数のストレージクラスを選択できます。
