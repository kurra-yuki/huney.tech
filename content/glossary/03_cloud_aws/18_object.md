# S3オブジェクト

## 正式名称

**S3 Object**

## 一言でいうと

**Amazon S3に保存されるデータの基本単位**

## 初心者向け説明

画像や動画などのデータをS3ではオブジェクトとして扱います。オブジェクトはバケット内でキーによって識別されます。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「Amazon S3に保存されるデータの基本単位」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
