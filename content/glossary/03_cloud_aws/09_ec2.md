# Amazon EC2

## 正式名称

**Amazon Elastic Compute Cloud**

## 一言でいうと

**AWS上で仮想サーバーなどのコンピューティング能力を利用できるサービス**

## 初心者向け説明

必要な性能やOSなどを選び、EC2インスタンスとしてコンピューティング環境を起動できます。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「AWS上で仮想サーバーなどのコンピューティング能力を利用できるサービス」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
