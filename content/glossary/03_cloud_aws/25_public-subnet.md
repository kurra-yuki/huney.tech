# パブリックサブネット

## 正式名称

**Public Subnet**

## 一言でいうと

**インターネットゲートウェイへのルートを持つサブネット**

## 初心者向け説明

一般にルートテーブルにインターネットゲートウェイへの経路を持つサブネットをこう呼びます。リソースが実際にインターネット通信できるかは他の設定にも依存します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「インターネットゲートウェイへのルートを持つサブネット」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
