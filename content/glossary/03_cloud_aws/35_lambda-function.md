# Lambda関数

## 正式名称

**Lambda Function**

## 一言でいうと

**AWS Lambdaで実行するコードと設定をまとめた単位**

## 初心者向け説明

イベントを受けて処理を実行するコードをLambda関数として作成します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「AWS Lambdaで実行するコードと設定をまとめた単位」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
