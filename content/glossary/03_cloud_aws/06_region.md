# リージョン

## 正式名称

**AWS Region**

## 一言でいうと

**AWSのインフラストラクチャが配置されている地理的なエリア**

## 初心者向け説明

AWSでは世界各地にリージョンがあり、システムを構築するときに利用するリージョンを選択します。利用可能サービスや料金などがリージョンによって異なる場合があります。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「AWSのインフラストラクチャが配置されている地理的なエリア」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
