# AWS Lambda

## 正式名称

**AWS Lambda**

## 一言でいうと

**サーバーを自分で管理せずにコードを実行できるサーバーレスコンピューティングサービス**

## 初心者向け説明

イベントなどをきっかけにLambda関数を実行できます。基盤となるサーバーのプロビジョニングや管理はAWSが行います。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「サーバーを自分で管理せずにコードを実行できるサーバーレスコンピューティングサービス」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
