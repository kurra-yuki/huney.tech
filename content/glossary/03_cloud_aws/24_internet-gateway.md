# インターネットゲートウェイ

## 正式名称

**Internet Gateway (IGW)**

## 一言でいうと

**VPCとインターネット間の通信を可能にするためのVPCコンポーネント**

## 初心者向け説明

VPCへアタッチして利用します。ただし、IGWを付けるだけでリソースが自動的にインターネット公開されるわけではありません。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「VPCとインターネット間の通信を可能にするためのVPCコンポーネント」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
