# ルートテーブル

## 正式名称

**Route Table**

## 一言でいうと

**ネットワークトラフィックをどこへ送るか決めるルールの集合**

## 初心者向け説明

VPC内の通信やインターネットなどへの通信経路を設定します。ネットワーク編で学んだルーティングの知識とつながります。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「ネットワークトラフィックをどこへ送るか決めるルールの集合」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
