# セキュリティグループ

## 正式名称

**Security Group**

## 一言でいうと

**AWSリソースへの通信を制御する仮想ファイアウォール**

## 初心者向け説明

EC2などのリソースに対して、許可するインバウンド・アウトバウンドトラフィックをルールとして設定します。ステートフルに動作します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「AWSリソースへの通信を制御する仮想ファイアウォール」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
