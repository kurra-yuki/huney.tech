# Amazon VPC

## 正式名称

**Amazon Virtual Private Cloud**

## 一言でいうと

**AWS上に論理的に分離された仮想ネットワークを作るサービス**

## 初心者向け説明

CIDRブロックを指定してネットワークを作成し、その中にサブネットやルートテーブルなどを構成します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「AWS上に論理的に分離された仮想ネットワークを作るサービス」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
