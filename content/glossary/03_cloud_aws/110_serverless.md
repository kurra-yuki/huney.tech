# サーバーレス

## 正式名称

**Serverless**

## 一言でいうと

**利用者がサーバーのプロビジョニングや管理を直接行わずにアプリケーションを実行する考え方**

## 初心者向け説明

サーバー自体が存在しないという意味ではありません。基盤の管理をクラウド事業者に任せ、利用者はコードや設定などに集中します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「利用者がサーバーのプロビジョニングや管理を直接行わずにアプリケーションを実行する考え方」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
