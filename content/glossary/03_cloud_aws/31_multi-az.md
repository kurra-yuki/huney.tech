# Multi-AZ

## 正式名称

**Multi-AZ Deployment**

## 一言でいうと

**複数のアベイラビリティーゾーンを利用して可用性を高める構成**

## 初心者向け説明

RDSなどで、複数AZを利用して障害時の可用性向上を図るための仕組み・構成です。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「複数のアベイラビリティーゾーンを利用して可用性を高める構成」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
