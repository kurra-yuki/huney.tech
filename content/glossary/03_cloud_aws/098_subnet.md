# サブネット

## 正式名称

**Subnet**

## 一言でいうと

**VPCのIPアドレス範囲を分割したネットワーク**

## 初心者向け説明

VPC内のリソースを配置する単位のひとつです。AWSのサブネットは1つのアベイラビリティーゾーンに属します。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「VPCのIPアドレス範囲を分割したネットワーク」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
