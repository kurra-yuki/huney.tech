# CDN

## 正式名称

**Content Delivery Network**

## 一言でいうと

**複数の配信拠点を利用してコンテンツを効率よく届ける仕組み**

## 初心者向け説明

利用者に近い配信拠点からコンテンツを返すことで、遅延やオリジンへの負荷を減らすことができます。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「複数の配信拠点を利用してコンテンツを効率よく届ける仕組み」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
