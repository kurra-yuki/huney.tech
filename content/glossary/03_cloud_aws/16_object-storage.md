# オブジェクトストレージ

## 正式名称

**Object Storage**

## 一言でいうと

**データをオブジェクト単位で保存・管理するストレージ方式**

## 初心者向け説明

ファイルの内容だけでなく、メタデータなども含むオブジェクトとしてデータを管理します。Amazon S3が代表例です。

## ポイント

- クラウド / AWSを学ぶうえで重要な用語
- まずは「データをオブジェクト単位で保存・管理するストレージ方式」と覚えればOK
- 詳しい仕組みは関連記事から段階的に学べる
