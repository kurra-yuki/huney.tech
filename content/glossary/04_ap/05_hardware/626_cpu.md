# CPU

## 正式名称

**Central Processing Unit**

## 一言でいうと

**コンピュータの命令を実行する中心的な処理装置**

## 初心者向け説明

CPUは、**コンピュータの命令を実行する中心的な処理装置**です。ハードウェアやコンピュータアーキテクチャを理解するうえで重要な用語です。まずは「何のための仕組みか」を押さえ、関連する用語とセットで理解すると整理しやすくなります。

## ポイント

- コンピュータの命令を実行する中心的な処理装置
- 正式名称は「Central Processing Unit」
- 関連する仕組みとセットで覚えると理解しやすい
