# HDL

## 正式名称

**Hardware Description Language**

## 一言でいうと

**デジタル回路の構造や動作を記述するための言語**

## 初心者向け説明

HDLは、**デジタル回路の構造や動作を記述するための言語**です。ハードウェアやコンピュータアーキテクチャを理解するうえで重要な用語です。まずは「何のための仕組みか」を押さえ、関連する用語とセットで理解すると整理しやすくなります。

## ポイント

- デジタル回路の構造や動作を記述するための言語
- 正式名称は「Hardware Description Language」
- 関連する仕組みとセットで覚えると理解しやすい
