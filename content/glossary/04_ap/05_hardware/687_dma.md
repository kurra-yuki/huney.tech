# DMA

## 正式名称

**Direct Memory Access**

## 一言でいうと

**CPUを介さず入出力装置と主記憶の間で直接データ転送する方式**

## 初心者向け説明

DMAは、**CPUを介さず入出力装置と主記憶の間で直接データ転送する方式**です。ハードウェアやコンピュータアーキテクチャを理解するうえで重要な用語です。まずは「何のための仕組みか」を押さえ、関連する用語とセットで理解すると整理しやすくなります。

## ポイント

- CPUを介さず入出力装置と主記憶の間で直接データ転送する方式
- 正式名称は「Direct Memory Access」
- 関連する仕組みとセットで覚えると理解しやすい
