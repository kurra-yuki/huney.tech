# CISC

## 正式名称

**Complex Instruction Set Computer**

## 一言でいうと

**複雑で高機能な命令を含む多くの命令を持たせる設計思想**

## 初心者向け説明

CISCは、**複雑で高機能な命令を含む多くの命令を持たせる設計思想**です。ハードウェアやコンピュータアーキテクチャを理解するうえで重要な用語です。まずは「何のための仕組みか」を押さえ、関連する用語とセットで理解すると整理しやすくなります。

- 複雑で高機能な命令を含む多くの命令を持たせる設計思想
