# レインボーテーブル攻撃

## 正式名称

**Rainbow Table Attack**

## 一言でいうと

**事前計算したハッシュ値の対応表を使ってパスワードを推測する攻撃。**

## 初心者向け説明

事前計算したハッシュ値の対応表を使ってパスワードを推測する攻撃。 情報セキュリティの学習では、何を守るための仕組み・用語なのかを意識して覚えると理解しやすくなります。
