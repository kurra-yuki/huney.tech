# プロキシサーバ

## 正式名称

**Proxy Server**

## 一言でいうと

**クライアントやサーバの代わりに通信を中継するサーバ。**

## 初心者向け説明

クライアントやサーバの代わりに通信を中継するサーバ。 情報セキュリティの学習では、何を守るための仕組み・用語なのかを意識して覚えると理解しやすくなります。

## ポイント

- **役割**：クライアントやサーバの代わりに通信を中継するサーバ。
- **試験対策**：似た用語との違いを確認しましょう。
- **実務での視点**：目的や利用場面に応じて適切に扱います。
