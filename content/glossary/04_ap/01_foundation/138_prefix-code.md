# 接頭語符号

## 正式名称

**Prefix Code（プレフィックスコード）**

## 一言でいうと

**別の符号の先頭と重ならないようにした符号**

## 初心者向け説明

可変長符号では、データごとに符号の長さが異なるため、どこまでが1つの符号なのか分からなくなる可能性があります。

そこで、

> ある符号が、別の符号の先頭部分にならない

ように作ります。

例えば、

```text
A → 0
B → 10
C → 110
D → 111
```

では、どの符号も別の符号の先頭部分になっていません。

そのため、先頭から順番に符号を読み取れます。

## ポイント

- 可変長符号を区切りやすくする
- ある符号が別の符号の先頭にならない
- ハフマン符号は接頭語符号になる
