# サイクリックグラフ

## 正式名称

**Cyclic Graph（サイクリックグラフ）**

## 一言でいうと

**ぐるっと一周できるグラフ**

## 初心者向け説明

サイクリックグラフとは、**閉路（Cycle）を持つグラフ**です。

例えば、

```text
A ----- B
|       |
D ----- C
```

では、

```text
A → B → C → D → A
```

と辺をたどることで、元のAへ戻れます。

このように一周できる経路が存在するグラフをサイクリックグラフと呼びます。

## ポイント

- 閉路を持つグラフ
- 出発した頂点へ戻る経路が存在する
- アサイクリックグラフと対になる考え方
