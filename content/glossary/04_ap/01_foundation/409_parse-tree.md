# 構文木

## 正式名称

**Parse Tree（パースツリー）**

## 一言でいうと

**プログラムや式の文法的な構造を木で表したもの**

## 初心者向け説明

構文木とは、構文解析によって確認したプログラムや式の構造を、木の形で表現したものです。

例えば、

```text
1 + 2 * 3
```

という式を簡単に表すと、

```text
        +
       / \
      1   *
         / \
        2   3
```

のようになります。

この構造を見ることで、

```text
2 * 3
```

を先に処理してから、

```text
1 + 6
```

を計算するという関係も分かりやすくなります。

## ポイント

- 構文解析の結果を木構造で表現する
- プログラムや式の階層構造が分かる
- 演算の優先順位なども表現できる
