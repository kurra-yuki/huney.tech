# 閉路

## 正式名称

**Cycle（サイクル）**

## 一言でいうと

**一周して出発地点へ戻る経路**

## 初心者向け説明

閉路とは、ある頂点から出発して辺をたどり、再び同じ頂点へ戻る経路です。

例えば、

```text
A ----- B
|       |
D ----- C
```

なら、

```text
A → B → C → D → A
```

が閉路です。

閉路が存在するグラフをサイクリックグラフと呼びます。

## ポイント

- 出発した頂点へ戻る
- サイクリックグラフを判断する重要な要素
- 木には閉路が存在しない
