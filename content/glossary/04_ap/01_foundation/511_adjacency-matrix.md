# 隣接行列

## 正式名称

**Adjacency Matrix（アジャセンシーマトリックス）**

## 一言でいうと

**グラフの接続関係を行列で表したもの**

## 初心者向け説明

隣接行列とは、頂点同士の接続関係を表形式の行列で表現する方法です。

例えば、

```text
A ----- B
|
C
```

なら、

|   | A | B | C |
|---|---:|---:|---:|
| A | 0 | 1 | 1 |
| B | 1 | 0 | 0 |
| C | 1 | 0 | 0 |

のように表せます。

基本的には、

```text
接続あり = 1
接続なし = 0
```

です。

無向グラフでは、隣接行列は基本的に対称になります。

## ポイント

- 接続関係を行列で表す
- 接続ありを1、なしを0で表すことが多い
- 重み付きグラフでは重みを格納する場合もある
