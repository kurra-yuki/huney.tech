# 補集合

## 正式名称

**Complement（コンプリメント）**

## 一言でいうと

**全体の中から「Aではないもの」を集めた集合**

## 初心者向け説明

補集合とは、あらかじめ決めた全体集合の中で、対象となる集合に含まれていない要素を集めたものです。

例えば、

```text
全体集合 U = {1, 2, 3, 4, 5}
A = {1, 2, 3}
```

なら、Aに含まれていない、

```text
{4, 5}
```

がAの補集合です。

論理演算では**NOT**に対応する考え方です。

## ポイント

- 補集合を考えるには全体集合が必要
- 「Aではないもの」と考えると分かりやすい
- 論理演算のNOTに対応する
