# 権威DNSサーバー

## 正式名称

**Authoritative DNS Server**

## 一言でいうと

**担当ドメインの正式なDNS情報を持つサーバー**

## 初心者向け説明

権威DNSサーバーは、担当ドメインの正式なDNS情報を持つサーバーです。ネットワークの仕組みを理解するときは、「何をするための技術・用語なのか」を押さえると整理しやすくなります。
