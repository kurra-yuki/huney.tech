# ハミング符号

## 正式名称

**Hamming Code**

## 一言でいうと

**誤りの検出だけでなく訂正もできる符号**

## 初心者向け説明

ハミング符号は、誤りの検出だけでなく訂正もできる符号です。ネットワークの仕組みを理解するときは、「何をするための技術・用語なのか」を押さえると整理しやすくなります。

## ポイント

- 誤りの検出だけでなく訂正もできる符号
- 「伝送技術」の内容と関連する
