# キャッシュDNSサーバー

## 正式名称

**Caching DNS Server**

## 一言でいうと

**利用者の代わりに名前解決し結果を一時保存するDNSサーバー**

## 初心者向け説明

キャッシュDNSサーバーは、利用者の代わりに名前解決し結果を一時保存するDNSサーバーです。ネットワークの仕組みを理解するときは、「何をするための技術・用語なのか」を押さえると整理しやすくなります。
