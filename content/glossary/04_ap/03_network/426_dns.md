# DNS

## 正式名称

**Domain Name System**

## 一言でいうと

**ドメイン名とIPアドレスなどを対応付ける仕組み**

## 初心者向け説明

DNSは、ドメイン名とIPアドレスなどを対応付ける仕組みです。ネットワークの仕組みを理解するときは、「何をするための技術・用語なのか」を押さえると整理しやすくなります。

## ポイント

- ドメイン名とIPアドレスなどを対応付ける仕組み
- 「アプリケーション層のプロトコル」の内容と関連する
- 似た用語と役割の違いをセットで覚えると理解しやすい
