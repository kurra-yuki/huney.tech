# デフォルトゲートウェイ

## 正式名称

**Default Gateway**

## 一言でいうと

**別ネットワークへ通信するとき最初に送る相手**

デフォルトゲートウェイは、別ネットワークへ通信するとき最初に送る相手です。ネットワークの仕組みを理解するときは、「何をするための技術・用語なのか」を押さえると整理しやすくなります。
