# プライベートIPアドレス

## 正式名称

**Private IP Address**

## 一言でいうと

**組織や家庭内のネットワークで自由に使えるIPv4アドレス**

## 初心者向け説明

プライベートIPアドレスは、組織や家庭内のネットワークで自由に使えるIPv4アドレスです。ネットワークの仕組みを理解するときは、「何をするための技術・用語なのか」を押さえると整理しやすくなります。
