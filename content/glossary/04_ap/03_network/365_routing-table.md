# ルーティングテーブル

## 正式名称

**Routing Table**

## 一言でいうと

**パケットをどこへ転送するかを決めるための経路表**

## 初心者向け説明

ルーティングテーブルは、パケットをどこへ転送するかを決めるための経路表です。ネットワークの仕組みを理解するときは、「何をするための技術・用語なのか」を押さえると整理しやすくなります。
