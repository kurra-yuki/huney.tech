# HTTP

## 正式名称

**Hypertext Transfer Protocol**

## 一言でいうと

**WebブラウザとWebサーバーがデータをやり取りするプロトコル**

## 初心者向け説明

HTTPは、WebブラウザとWebサーバーがデータをやり取りするプロトコルです。ネットワークの仕組みを理解するときは、「何をするための技術・用語なのか」を押さえると整理しやすくなります。

## ポイント

- WebブラウザとWebサーバーがデータをやり取りするプロトコル
- 「アプリケーション層のプロトコル」の内容と関連する
- 似た用語と役割の違いをセットで覚えると理解しやすい
