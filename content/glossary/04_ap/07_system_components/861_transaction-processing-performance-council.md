# TPC

## 正式名称

**Transaction Processing Performance Council**

## 一言でいうと

**トランザクション処理性能のベンチマークを策定する団体**

## 初心者向け説明

TPC-Cなどのベンチマークでデータベース処理性能を評価します。

## ポイント

- トランザクション処理性能のベンチマークを策定する団体
- TPC-Cなどのベンチマークでデータベース処理性能を評価します。
- 「システムの性能特性と評価」の記事で扱う重要用語です。
