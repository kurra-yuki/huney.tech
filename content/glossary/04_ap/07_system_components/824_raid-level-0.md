# RAID 0

## 正式名称

**RAID Level 0**

## 一言でいうと

**データを複数ディスクに分散して高速化する方式**

## 初心者向け説明

ストライピングで性能を高めますが、冗長性はありません。

## ポイント

- データを複数ディスクに分散して高速化する方式
- ストライピングで性能を高めますが、冗長性はありません。
- 「ストレージ関連技術」の記事で扱う重要用語です。
