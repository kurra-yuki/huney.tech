# 2層クライアントサーバ

## 正式名称

**Two-Tier Client-Server Architecture**

## 一言でいうと

**クライアントとサーバの2層で構成する方式**

## 初心者向け説明

画面・業務処理の一部をクライアントが担い、サーバがデータ管理などを担当します。

## ポイント

- クライアントとサーバの2層で構成する方式
- 画面・業務処理の一部をクライアントが担い、サーバがデータ管理などを担当します。
- 「クライアントサーバシステム」の記事で扱う重要用語です。
