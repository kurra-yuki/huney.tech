# VDI

## 正式名称

**Virtual Desktop Infrastructure**

## 一言でいうと

**仮想デスクトップをサーバ側で提供する仕組み**

## 初心者向け説明

利用者は端末からサーバ上の仮想デスクトップへ接続します。シンクライアントの実現方法の一つです。

## ポイント

- 仮想デスクトップをサーバ側で提供する仕組み
- 利用者は端末からサーバ上の仮想デスクトップへ接続します。
- 「システムの処理形態」の記事で扱う重要用語です。
