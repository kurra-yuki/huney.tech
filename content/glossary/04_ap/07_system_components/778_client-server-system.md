# クライアントサーバシステム

## 正式名称

**Client-Server System**

## 一言でいうと

**要求する側とサービスを提供する側を分けた構成**

## 初心者向け説明

クライアントが要求を送信し、サーバが処理して結果を返します。

## ポイント

- 要求する側とサービスを提供する側を分けた構成
- クライアントが要求を送信し、サーバが処理して結果を返します。
- 「クライアントサーバシステム」の記事で扱う重要用語です。
