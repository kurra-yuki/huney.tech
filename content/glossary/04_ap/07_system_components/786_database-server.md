# DBサーバ

## 正式名称

**Database Server**

## 一言でいうと

**データベースを管理するサーバ**

## 初心者向け説明

データの検索・追加・更新などを担当します。

## ポイント

- データベースを管理するサーバ
- データの検索・追加・更新などを担当します。
- 「クライアントサーバシステム」の記事で扱う重要用語です。
