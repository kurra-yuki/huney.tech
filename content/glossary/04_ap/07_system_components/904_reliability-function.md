# 信頼度

## 正式名称

**Reliability Function**

## 一言でいうと

**一定時間故障せずに動作する確率**

## 初心者向け説明

一定故障率λではR(t)=e^(−λt)です。

## ポイント

- 一定時間故障せずに動作する確率
- 一定故障率λではR(t)=e^(−λt)です。
- 「システムの信頼性特性と評価」の記事で扱う重要用語です。
