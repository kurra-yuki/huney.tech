# ソフトウェアモニタ

## 正式名称

**Software Monitor**

## 一言でいうと

**ソフトウェアで稼働状況を監視する仕組み**

## 初心者向け説明

CPU使用率やメモリ使用量などをOSや監視ツールから取得します。

## ポイント

- ソフトウェアで稼働状況を監視する仕組み
- CPU使用率やメモリ使用量などをOSや監視ツールから取得します。
- 「システムの性能特性と評価」の記事で扱う重要用語です。
