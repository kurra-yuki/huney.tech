# サーバ

## 正式名称

**Server**

## 一言でいうと

**要求を受けてサービスを提供する側**

## 初心者向け説明

Webページの提供やデータベース処理などを担当します。

## ポイント

- 要求を受けてサービスを提供する側
- Webページの提供やデータベース処理などを担当します。
- 「クライアントサーバシステム」の記事で扱う重要用語です。
