# APサーバ

## 正式名称

**Application Server**

## 一言でいうと

**業務ロジックを実行するサーバ**

## 初心者向け説明

ログイン判定や注文処理などアプリケーション固有の処理を担当します。

## ポイント

- 業務ロジックを実行するサーバ
- ログイン判定や注文処理などアプリケーション固有の処理を担当します。
- 「クライアントサーバシステム」の記事で扱う重要用語です。
