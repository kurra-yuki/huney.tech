# 3層クライアントサーバ

## 正式名称

**Three-Tier Client-Server Architecture**

## 一言でいうと

**表示・業務処理・データ管理を分離する方式**

## 初心者向け説明

プレゼンテーション層、アプリケーション層、データ層を分け、変更や保守をしやすくします。

## ポイント

- 表示・業務処理・データ管理を分離する方式
- プレゼンテーション層、アプリケーション層、データ層を分け、変更や保守をしやすくします。
- 「クライアントサーバシステム」の記事で扱う重要用語です。
