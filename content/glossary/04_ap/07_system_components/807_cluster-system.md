# クラスタシステム

## 正式名称

**Cluster System**

## 一言でいうと

**複数のサーバを協調動作させるシステム**

## 初心者向け説明

冗長化や処理分散を実現するための構成です。

## ポイント

- 複数のサーバを協調動作させるシステム
- 冗長化や処理分散を実現するための構成です。
- 「高信頼性・高性能システム」の記事で扱う重要用語です。
