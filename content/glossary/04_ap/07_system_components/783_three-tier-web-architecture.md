# Web3層構造

## 正式名称

**Three-Tier Web Architecture**

## 一言でいうと

**Web・AP・DBの3つの役割に分ける構成**

## 初心者向け説明

WebサーバがHTTP要求を受け、APサーバが業務処理し、DBサーバがデータを管理します。

## ポイント

- Web・AP・DBの3つの役割に分ける構成
- WebサーバがHTTP要求を受け、APサーバが業務処理し、DBサーバがデータを管理します。
