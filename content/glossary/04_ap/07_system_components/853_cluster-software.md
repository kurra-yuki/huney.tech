# クラスタソフトウェア

## 正式名称

**Cluster Software**

## 一言でいうと

**複数サーバの連携や切替を管理するソフトウェア**

## 初心者向け説明

障害検知やフェールオーバーなどを制御し、サービス継続を支援します。

## ポイント

- 複数サーバの連携や切替を管理するソフトウェア
- 障害検知やフェールオーバーなどを制御し、サービス継続を支援します。
- 「仮想化技術」の記事で扱う重要用語です。
