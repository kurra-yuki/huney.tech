# 負荷分散クラスタ

## 正式名称

**Load Balancing Cluster**

## 一言でいうと

**処理要求を複数台に分散するクラスタ**

## 初心者向け説明

アクセス集中時の性能や処理能力を改善します。

## ポイント

- 処理要求を複数台に分散するクラスタ
- アクセス集中時の性能や処理能力を改善します。
- 「高信頼性・高性能システム」の記事で扱う重要用語です。
