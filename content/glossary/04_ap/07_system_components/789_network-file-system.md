# NFS

## 正式名称

**Network File System**

## 一言でいうと

**ネットワーク越しにファイルを共有する仕組み**

## 初心者向け説明

主にUNIX系環境で、離れたサーバのファイルをローカルに近い操作感で利用します。

## ポイント

- ネットワーク越しにファイルを共有する仕組み
- 主にUNIX系環境で、離れたサーバのファイルをローカルに近い操作感で利用します。
- 「クライアントサーバシステム」の記事で扱う重要用語です。
