# サーバ仮想化

## 正式名称

**Server Virtualization**

## 一言でいうと

**1台の物理サーバ上に複数の仮想サーバを作る技術**

## 初心者向け説明

CPU・メモリなどを仮想的に分割して複数のOS環境を実行します。

## ポイント

- 1台の物理サーバ上に複数の仮想サーバを作る技術
- CPU・メモリなどを仮想的に分割して複数のOS環境を実行します。
- 「仮想化技術」の記事で扱う重要用語です。
