# 共通原因故障

## 正式名称

**Common Cause Failure**

## 一言でいうと

**同じ原因で複数機器が同時に故障すること**

## 初心者向け説明

二重化した回線が同じ管路を通る場合などに注意します。

## ポイント

- 同じ原因で複数機器が同時に故障すること
- 二重化した回線が同じ管路を通る場合などに注意します。
- 「システムの信頼性特性と評価」の記事で扱う重要用語です。
