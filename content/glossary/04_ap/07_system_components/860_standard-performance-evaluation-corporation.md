# SPEC

## 正式名称

**Standard Performance Evaluation Corporation**

## 一言でいうと

**コンピュータ性能評価の標準ベンチマークを提供する団体**

## 初心者向け説明

SPEC CPUなどのベンチマーク群があり、用途に応じた指標で評価します。

## ポイント

- コンピュータ性能評価の標準ベンチマークを提供する団体
- SPEC CPUなどのベンチマーク群があり、用途に応じた指標で評価します。
- 「システムの性能特性と評価」の記事で扱う重要用語です。
