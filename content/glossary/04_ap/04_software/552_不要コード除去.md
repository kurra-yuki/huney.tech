# 不要コード除去

## 正式名称

**Dead Code Elimination**

## 一言でいうと

**実行結果に影響しない不要なコードを削除する最適化**

## 初心者向け説明

不要コード除去は、実行結果に影響しない不要なコードを削除する最適化です。言語処理ツールを理解するうえで重要な基本用語で、応用情報では名称だけでなく「何をするものか」を対応付けて覚えることが大切です。

## ポイント

-   実行結果に影響しない不要なコードを削除する最適化
-   言語処理ツールの流れの中で役割を整理すると覚えやすい
-   似た用語との違いもセットで確認する
