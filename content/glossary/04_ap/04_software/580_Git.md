# Git

## 正式名称

**Git**

## 一言でいうと

**各開発者が履歴を含むリポジトリを保持できる分散型バージョン管理システム**

## 初心者向け説明

Gitは、各開発者が履歴を含むリポジトリを保持できる分散型バージョン管理システムです。開発ツールを理解するうえで重要な基本用語で、応用情報では名称だけでなく「何をするものか」を対応付けて覚えることが大切です。

## ポイント

-   各開発者が履歴を含むリポジトリを保持できる分散型バージョン管理システム
-   開発ツールの流れの中で役割を整理すると覚えやすい
-   似た用語との違いもセットで確認する
