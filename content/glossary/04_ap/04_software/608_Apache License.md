# Apache License

## 正式名称

**Apache License 2.0**

## 一言でいうと

## 初心者向け説明

Apache
Licenseは、特許条項なども定める代表的なOSSライセンスです。UNIX系OSを理解するうえで重要な基本用語で、応用情報では名称だけでなく「何をするものか」を対応付けて覚えることが大切です。
