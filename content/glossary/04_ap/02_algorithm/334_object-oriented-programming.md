# オブジェクト指向

## 正式名称

**Object-Oriented Programming**

## 一言でいうと

**データと処理をオブジェクトとしてまとめて考える方法**

## 初心者向け説明

対象をオブジェクトとして捉え、関連するデータと処理をまとめながらプログラムを構成する考え方です。

## ポイント

- クラスとインスタンスが登場する
- カプセル化・継承・多態性などが重要
- 複数の現代言語で利用される
