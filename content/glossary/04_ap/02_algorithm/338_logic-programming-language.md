# 論理型言語

## 正式名称

**Logic Programming Language**

## 一言でいうと

**事実と規則から条件を満たす答えを導く言語**

## 初心者向け説明

処理手順を細かく記述する代わりに、事実や規則を定義し、問い合わせに対して推論によって答えを求める言語です。

## ポイント

- Prologが代表例
- 事実・規則・問い合わせを利用する
- 宣言型プログラミングと関係が深い
