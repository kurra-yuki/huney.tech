# ハッシュ関数

## 正式名称

**Hash Function**

## 一言でいうと

**キーからハッシュ値を計算する関数**

## 初心者向け説明

検索したいキーを入力として、ハッシュ表上の位置を決めるための値を計算する関数です。

## ポイント

- 同じ入力から同じハッシュ値を得る
- ハッシュ表で利用される
- 異なるキーが同じ値になる衝突が起こり得る
