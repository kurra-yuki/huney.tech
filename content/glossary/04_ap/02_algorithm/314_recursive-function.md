# 再帰関数

## 正式名称

**Recursive Function**

## 一言でいうと

**自分自身を呼び出す関数**

## 初心者向け説明

処理の途中で自分自身を呼び出し、より小さな問題へ分解しながら答えを求める関数です。

## ポイント

- 基底条件が必要
- 引数などを変化させて終了へ近づける
- 呼出しごとにスタックを利用する
