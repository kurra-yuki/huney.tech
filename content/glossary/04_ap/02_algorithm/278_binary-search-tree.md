# 二分探索木

## 正式名称

**Binary Search Tree**

## 一言でいうと

**大小関係を利用して探索しやすくした二分木**

## 初心者向け説明

各ノードについて、一般に左側へ小さい値、右側へ大きい値を配置することで探索しやすくした二分木です。

## ポイント

- 大小関係を利用して探索する
- バランスがよければ探索はおおむねO(log n)
- 偏ると最悪O(n)になる
