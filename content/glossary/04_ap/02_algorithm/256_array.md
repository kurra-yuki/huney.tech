# 配列

## 正式名称

**Array**

## 一言でいうと

**複数の要素を添字で管理するデータ構造**

## 初心者向け説明

複数のデータを並べて保持し、添字を使って目的の要素へアクセスするデータ構造です。

## ポイント

- 添字で要素を指定できる
- 一般にランダムアクセスがしやすい
- 挿入・削除では要素移動が必要になる場合がある
