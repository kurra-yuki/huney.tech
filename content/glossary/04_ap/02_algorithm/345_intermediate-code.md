# 中間コード

## 正式名称

**Intermediate Code**

## 一言でいうと

**ソースコードと最終的な機械語などの中間に位置する表現**

## 初心者向け説明

ソースコードを直接機械語へ変換するのではなく、処理系内部で扱いやすい中間的な形式として利用されるコードです。

## ポイント

- Javaのバイトコードが代表例
- 仮想マシンで実行される場合がある
- 最適化や移植性に利用される
