# JVM

## 正式名称

**Java Virtual Machine**

## 一言でいうと

**Javaのバイトコードを実行するための仮想マシン**

## 初心者向け説明

Javaコンパイラが生成したバイトコードを実行するための環境で、各プラットフォームの違いを吸収する役割を持ちます。

## ポイント

- Java Virtual Machineの略
- Javaバイトコードを実行する
- 環境ごとに対応したJVMが用意される
