# ソースコード

## 正式名称

**Source Code**

## 一言でいうと

**人間がプログラム言語で記述したプログラムの内容**

## 初心者向け説明

CやJava、Pythonなどのプログラム言語を使って、人間が読み書きできる形で記述したコードです。

## ポイント

- ソースプログラムの内容を指す
- コンパイルや解釈の対象になる
- プログラム言語の文法に従って記述する
