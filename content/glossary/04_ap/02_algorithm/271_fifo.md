# FIFO

## 正式名称

**First In, First Out**

## 一言でいうと

**最初に入れたものを最初に取り出す方式**

## 初心者向け説明

キューの基本原則で、日本語では先入れ先出しと呼ばれます。

## ポイント

- First In, First Outの略
- キューの基本動作
- レジの行列のイメージで理解しやすい
