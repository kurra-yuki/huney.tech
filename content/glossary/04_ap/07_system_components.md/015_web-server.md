# Webサーバ

## 正式名称

**Web Server**

## 一言でいうと

**HTTP要求を受けてWebコンテンツを提供するサーバ**

## 初心者向け説明

静的ファイルの配信やAPサーバへのリバースプロキシなどを担当します。

## ポイント

- HTTP要求を受けてWebコンテンツを提供するサーバ
- 静的ファイルの配信やAPサーバへのリバースプロキシなどを担当します。
- 「クライアントサーバシステム」の記事で扱う重要用語です。
