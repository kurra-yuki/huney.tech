# JSON

## 正式名称

**JavaScript Object Notation**

## 一言でいうと

**キーと値などでデータを表す軽量な形式**

## 初心者向け説明

Web APIなどでよく使われます。 例えば、はちみつ屋さんの業務やシステムを考えるときも、この考え方が役立ちます。

## ポイント

- キーと値などでデータを表す軽量な形式
- Web APIなどでよく使われます。
