# Knowledge Base

## 正式名称

**Knowledge Base**

## 一言でいうと

**既知の問題や技術情報を調べるための情報集**

## 初心者向け説明

Error Messageや症状から関連する技術情報、既知問題、対処方法などを確認するときに利用します。

## ポイント

- 既知の問題や技術情報を調べるための情報集
- NCA 7.5では「Knowledge Baseは何のためのものか」を関連機能とセットで理解する
- 単語だけでなく、Nutanix全体の中での役割を整理する
