# Root Cause

## 正式名称

**Root Cause**

## 一言でいうと

**問題を発生させた根本的な原因**

## 初心者向け説明

表面に見えている症状ではなく、その問題を引き起こした本当の原因を指します。障害対応では症状と原因を分けて考えることが重要です。

## ポイント

- 問題を発生させた根本的な原因
- NCA 7.5では「Root Causeは何のためのものか」を関連機能とセットで理解する
- 単語だけでなく、Nutanix全体の中での役割を整理する
