# Apache Tomcat

## 正式名称

**Apache Tomcat**

## 一言でいうと

**JavaのWebアプリケーションを動かすためのServletコンテナ / Webコンテナ**

## 初心者向け説明

Java ServletやJakarta Server PagesなどのWeb関連仕様を実装するオープンソースソフトウェアです。Apache HTTP Serverとは名前が似ていますが、主な役割は異なります。

## ポイント

- 「Apache Tomcat」はサーバー分野を学ぶうえで重要な用語
- まずは「JavaのWebアプリケーションを動かすためのServletコンテナ / Webコンテナ」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
