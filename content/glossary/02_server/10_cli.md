# CLI

## 正式名称

**Command Line Interface**

## 一言でいうと

**文字でコマンドを入力してコンピューターを操作するインターフェース**

## 初心者向け説明

ボタンやアイコンを操作する代わりに、ターミナルなどからコマンドを入力してコンピューターを操作します。Linuxサーバーの管理では頻繁に利用されます。

## ポイント

- 「CLI」はサーバー分野を学ぶうえで重要な用語
- まずは「文字でコマンドを入力してコンピューターを操作するインターフェース」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
