# root

## 正式名称

**root user**

## 一言でいうと

**Linuxで非常に強い管理権限を持つユーザー**

## 初心者向け説明

rootは設定変更やユーザー管理など幅広い操作ができます。その分、誤操作の影響も大きいため、普段は一般ユーザーで作業し、必要な操作だけsudoを使う考え方が重要です。
