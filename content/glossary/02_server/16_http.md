# HTTP

## 正式名称

**Hypertext Transfer Protocol**

## 一言でいうと

**Webでクライアントとサーバーが情報をやり取りするためのプロトコル**

## 初心者向け説明

ブラウザがWebサーバーへリクエストを送り、サーバーがレスポンスを返すときなどに利用されます。Web通信を支える基本的なプロトコルです。

## ポイント

- 「HTTP」はサーバー分野を学ぶうえで重要な用語
- まずは「Webでクライアントとサーバーが情報をやり取りするためのプロトコル」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
