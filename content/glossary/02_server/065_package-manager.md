# パッケージマネージャー

## 正式名称

**Package Manager**

## 一言でいうと

**Linuxのパッケージを検索・インストール・更新・削除する仕組み**

## 初心者向け説明

UbuntuやDebian系ではapt、RHEL系ではdnfなどが利用されます。設定されたリポジトリから必要なパッケージを取得して管理します。

## ポイント

- Linuxのパッケージを検索・インストール・更新・削除する仕組み
- UbuntuやDebian系ではapt、RHEL系ではdnfなどが利用されます。設定されたリポジトリから必要なパッケージを取得して管理します。
