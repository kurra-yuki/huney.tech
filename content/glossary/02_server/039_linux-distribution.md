# Linuxディストリビューション

## 正式名称

**Linux Distribution**

## 一言でいうと

**Linuxカーネルと各種ソフトウェアを組み合わせて利用できる形にしたOS**

## 初心者向け説明

Linuxカーネルに基本コマンドやパッケージ管理ツールなどを組み合わせたものです。Ubuntu、Debian、Red Hat Enterprise Linux、Amazon Linuxなどがあります。

- 「Linuxディストリビューション」はサーバー分野を学ぶうえで重要な用語
