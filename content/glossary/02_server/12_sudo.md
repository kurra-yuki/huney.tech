# sudo

## 正式名称

**superuser do**

## 一言でいうと

**許可されたユーザーが別ユーザーの権限でコマンドを実行する仕組み**

## 初心者向け説明

Linuxの管理作業などで、必要なコマンドだけを高い権限で実行するときに利用されます。sudoを使える範囲は設定によって制御できます。

## ポイント

- 「sudo」はサーバー分野を学ぶうえで重要な用語
- まずは「許可されたユーザーが別ユーザーの権限でコマンドを実行する仕組み」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
