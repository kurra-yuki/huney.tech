# ホームディレクトリ

## 正式名称

**Home Directory**

## 一言でいうと

**ユーザーごとに用意される作業用ディレクトリ**

## 初心者向け説明

一般的なLinuxでは、user01というユーザーなら/home/user01のようなホームディレクトリを持ちます。シェルでは「~」を使って自分のホームディレクトリを表せます。
