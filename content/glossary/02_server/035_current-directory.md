# カレントディレクトリ

## 正式名称

**Current Directory**

## 一言でいうと

**現在自分がいるディレクトリ**

## 初心者向け説明

pwdコマンドで現在のカレントディレクトリを確認できます。相対パスは、このカレントディレクトリを基準としてファイルやディレクトリの場所を指定します。
