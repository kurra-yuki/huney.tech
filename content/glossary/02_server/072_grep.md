# grep

## 正式名称

**grep**

## 一言でいうと

**テキストから指定した文字列に一致する行を検索するコマンド**

## 初心者向け説明

grep "ERROR" server.logのように使います。-iで大文字・小文字を区別せず検索したり、-nで行番号を表示したりできます。パイプと組み合わせることも多いコマンドです。

## ポイント
