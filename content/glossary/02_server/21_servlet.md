# Servlet

## 正式名称

**Jakarta Servlet**

## 一言でいうと

**JavaでWebリクエストを処理してレスポンスを生成するための仕組み**

## 初心者向け説明

JavaのWebアプリケーションで利用される技術です。TomcatなどのServletコンテナ上で動作し、HTTPリクエストに応じてサーバー側の処理を実行できます。

## ポイント

- 「Servlet」はサーバー分野を学ぶうえで重要な用語
- まずは「JavaでWebリクエストを処理してレスポンスを生成するための仕組み」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
