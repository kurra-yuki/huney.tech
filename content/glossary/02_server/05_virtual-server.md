# 仮想サーバー

## 正式名称

**Virtual Server**

## 一言でいうと

**仮想化技術によって作られた仮想的なサーバー**

## 初心者向け説明

1台の物理サーバー上に複数の仮想的なコンピューターを作り、それぞれを独立したサーバーとして利用できます。クラウドサービスでも重要な考え方です。

- 「仮想サーバー」はサーバー分野を学ぶうえで重要な用語
