# Webコンテナ

## 正式名称

**Web Container / Servlet Container**

## 一言でいうと

**ServletなどのJava Webコンポーネントを実行・管理する環境**

## 初心者向け説明

HTTPリクエストの受け付けやServletの実行など、Java Webアプリケーションを動かすために必要な機能を提供します。Tomcatが代表例です。

## ポイント

- 「Webコンテナ」はサーバー分野を学ぶうえで重要な用語
- まずは「ServletなどのJava Webコンポーネントを実行・管理する環境」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
