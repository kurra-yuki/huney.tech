# ユーザー

## 正式名称

**User**

## 一言でいうと

**Linuxを利用する人やサービスを識別する単位**

## 初心者向け説明

Linuxではuser01のような一般ユーザーだけでなく、サービス専用ユーザーを作成することもあります。ユーザーごとにUIDがあり、ファイルの所有者やプロセスの実行者としても利用されます。
