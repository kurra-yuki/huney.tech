# 物理サーバー

## 正式名称

**Physical Server**

## 一言でいうと

**実際のハードウェアとして存在するサーバー**

## 初心者向け説明

CPU、メモリ、ストレージ、ネットワークインターフェースなどを搭載した物理的なコンピューターを、サーバー用途で利用するものです。仮想サーバーと対比して使われることがあります。

## ポイント

- 「物理サーバー」はサーバー分野を学ぶうえで重要な用語
- まずは「実際のハードウェアとして存在するサーバー」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
