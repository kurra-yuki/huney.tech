# systemctl

## 正式名称

**systemctl**

## 一言でいうと

**systemdでサービスなどを操作するためのコマンド**

## 初心者向け説明

systemctl status sshのように状態を確認したり、systemctl startやstop、restart、enableなどを使ってサービスを管理できます。

## ポイント

- systemdでサービスなどを操作するためのコマンド
- systemctl status sshのように状態を確認したり、systemctl startやstop、restart、enableなどを使ってサービスを管理できます。
- Linuxサーバーの構築・運用を理解するうえで重要な基礎用語
