# 絶対パス

## 正式名称

**Absolute Path**

## 一言でいうと

**ルートディレクトリから目的地までをすべて指定するパス**

## 初心者向け説明

たとえば/home/user01/Documentsは絶対パスです。どのディレクトリにいても同じ場所を指すため、場所を明確に指定したいときに便利です。

## ポイント

- ルートディレクトリから目的地までをすべて指定するパス
