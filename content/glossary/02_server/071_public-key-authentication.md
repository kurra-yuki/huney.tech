# 公開鍵認証

## 正式名称

**Public Key Authentication**

## 一言でいうと

**公開鍵と秘密鍵を使ってSSHなどの利用者を認証する方式**

## 初心者向け説明

SSHの公開鍵認証では、秘密鍵をクライアント側で安全に管理し、対応する公開鍵をサーバーへ登録します。秘密鍵は他人へ渡さず、安全に保管することが重要です。

## ポイント

- 公開鍵と秘密鍵を使ってSSHなどの利用者を認証する方式
