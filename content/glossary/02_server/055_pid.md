# PID

## 正式名称

**Process ID**

## 一言でいうと

**実行中のプロセスを識別する番号**

## 初心者向け説明

psなどのコマンドでPIDを確認できます。killコマンドで特定のプロセスへシグナルを送る場合にもPIDを指定します。

## ポイント

- 実行中のプロセスを識別する番号
- psなどのコマンドでPIDを確認できます。killコマンドで特定のプロセスへシグナルを送る場合にもPIDを指定します。
