# リバースプロキシ

## 正式名称

**Reverse Proxy**

## 一言でいうと

**クライアントからのリクエストを受けて後ろのサーバーへ転送する仕組み**

## 初心者向け説明

外部からのリクエストをいったん受け取り、バックエンドにあるWebサーバーやアプリケーションサーバーなどへ転送します。Apache HTTP Serverやnginxなどで構成できます。

## ポイント

- 「リバースプロキシ」はサーバー分野を学ぶうえで重要な用語
- まずは「クライアントからのリクエストを受けて後ろのサーバーへ転送する仕組み」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
