# chown

## 正式名称

**change owner**

## 一言でいうと

**ファイルやディレクトリの所有者や所有グループを変更するコマンド**

## 初心者向け説明

たとえばchown minecraft:minecraft /opt/minecraftのように、所有者と所有グループを指定できます。サービス専用ユーザーへファイルを管理させるときにも使います。

## ポイント

- ファイルやディレクトリの所有者や所有グループを変更するコマンド
