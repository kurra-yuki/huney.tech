# パッケージ管理

## 正式名称

**Package Management**

## 一言でいうと

**ソフトウェアのインストールや更新などを管理する仕組み**

## 初心者向け説明

Linuxディストリビューションでは、ソフトウェアをパッケージとして管理します。Ubuntu系のAPTやRed Hat系のDNFなど、ディストリビューションによって利用するツールが異なります。

## ポイント

- 「パッケージ管理」はサーバー分野を学ぶうえで重要な用語
- まずは「ソフトウェアのインストールや更新などを管理する仕組み」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
