# リポジトリ

## 正式名称

**Repository**

## 一言でいうと

**Linuxで利用するパッケージが公開・管理されている場所**

## 初心者向け説明

aptやdnfは設定されたリポジトリの情報を使い、利用可能なパッケージを検索・取得します。どのリポジトリを利用するかはLinux環境によって異なります。

## ポイント

- Linuxで利用するパッケージが公開・管理されている場所
- aptやdnfは設定されたリポジトリの情報を使い、利用可能なパッケージを検索・取得します。どのリポジトリを利用するかはLinux環境によって異なります。
