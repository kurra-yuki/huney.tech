# パッケージ

## 正式名称

**Package**

## 一言でいうと

**Linuxへソフトウェアを導入・管理しやすい形にまとめたもの**

## 初心者向け説明

LinuxではJavaやGitなど多くのソフトウェアをパッケージとして導入できます。パッケージマネージャーを利用することでインストールや更新、削除を管理できます。
