# SSH

## 正式名称

**Secure Shell**

## 一言でいうと

**ネットワーク経由で別のコンピューターへ安全に接続・操作する仕組み**

## 初心者向け説明

SSHでは通信が暗号化されます。一般的にはTCP 22番ポートを利用し、ssh user01@192.168.1.10のようにユーザー名と接続先を指定して接続します。
