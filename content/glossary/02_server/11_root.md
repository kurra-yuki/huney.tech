# root

## 正式名称

**root user**

## 一言でいうと

**Linuxなどで非常に強い権限を持つ特権ユーザー**

## 初心者向け説明

システム全体に対して強い権限を持つユーザーです。重要な設定やファイルも変更できるため、必要以上にroot権限を使わないことが重要です。

## ポイント

- 「root」はサーバー分野を学ぶうえで重要な用語
- まずは「Linuxなどで非常に強い権限を持つ特権ユーザー」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
