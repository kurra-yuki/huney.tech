# Apache HTTP Server

## 正式名称

**Apache HTTP Server**

## 一言でいうと

**HTTP/HTTPSでWebコンテンツなどを提供する代表的なWebサーバーソフトウェア**

## 初心者向け説明

Apache Software Foundationが開発するオープンソースのWebサーバーソフトウェアです。静的コンテンツの配信やリバースプロキシ、アクセス制御など、さまざまな用途で利用できます。

## ポイント

- 「Apache HTTP Server」はサーバー分野を学ぶうえで重要な用語
