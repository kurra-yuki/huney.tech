# 依存関係

## 正式名称

**Dependency**

## 一言でいうと

**あるソフトウェアを動かすために別のソフトウェアが必要になる関係**

## 初心者向け説明

Linuxのパッケージマネージャーは、インストールするソフトウェアに必要な別のパッケージを確認し、依存関係を考慮して導入してくれます。

## ポイント

- あるソフトウェアを動かすために別のソフトウェアが必要になる関係
- Linuxのパッケージマネージャーは、インストールするソフトウェアに必要な別のパッケージを確認し、依存関係を考慮して導入してくれます。
- Linuxサーバーの構築・運用を理解するうえで重要な基礎用語
