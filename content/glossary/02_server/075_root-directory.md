# ルートディレクトリ

## 正式名称

**Root Directory**

## 一言でいうと

**Linuxのディレクトリ構造で最上位にある「/」**

## 初心者向け説明

Linuxのファイルシステムは「/」を頂点とした木構造になっています。/home、/etc、/varなどのディレクトリもすべてルートディレクトリの下に存在します。

- Linuxのディレクトリ構造で最上位にある「/」
