# Linux

## 正式名称

**Linux**

## 一言でいうと

**サーバーやクラウドで広く利用されているOS系統**

## 初心者向け説明

厳密にはLinuxはOSの中核となるLinuxカーネルを指します。実際にはLinuxカーネルとさまざまなソフトウェアを組み合わせたLinuxディストリビューションを、まとめてLinuxと呼ぶことも多くあります。

## ポイント

- 「Linux」はサーバー分野を学ぶうえで重要な用語
- まずは「サーバーやクラウドで広く利用されているOS系統」と覚えればOK
