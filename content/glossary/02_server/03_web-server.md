# Webサーバー

## 正式名称

**Web Server**

## 一言でいうと

**HTTPやHTTPSを使ってWebコンテンツなどを提供するサーバー**

## 初心者向け説明

ブラウザなどからHTTP/HTTPSのリクエストを受け取り、HTMLや画像などのWebコンテンツを返します。Apache HTTP Serverやnginxなどが代表的なWebサーバーソフトウェアです。

## ポイント

- 「Webサーバー」はサーバー分野を学ぶうえで重要な用語
- まずは「HTTPやHTTPSを使ってWebコンテンツなどを提供するサーバー」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
