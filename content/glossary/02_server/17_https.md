# HTTPS

## 正式名称

**Hypertext Transfer Protocol Secure**

## 一言でいうと

**HTTP通信をTLSによって保護する仕組み**

## 初心者向け説明

HTTPによる通信をTLSで保護し、通信内容の暗号化や通信相手の認証などに利用されます。現在のWebサイトでは広く利用されています。

## ポイント

- 「HTTPS」はサーバー分野を学ぶうえで重要な用語
- まずは「HTTP通信をTLSによって保護する仕組み」と覚えればOK
- 関連する仕組みは関連記事で段階的に学べる
