# JSP

## 正式名称

**Jakarta Server Pages**

## 一言でいうと

**Javaを利用したWebページ生成に使われるサーバーサイド技術**

## 初心者向け説明

Jakarta Server Pagesの略で、Java系Webアプリケーションで動的なWebページを生成するために利用される技術です。TomcatはJSPを処理できます。
