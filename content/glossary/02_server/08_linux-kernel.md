# Linuxカーネル

## 正式名称

**Linux Kernel**

## 一言でいうと

**Linux系OSの中核となる部分**

## 初心者向け説明

ハードウェア資源やプロセス、メモリなどを管理し、OSの中核となる機能を担当します。一般に「Linux」と呼ばれるOS環境は、Linuxカーネルと各種ソフトウェアを組み合わせて構成されています。
