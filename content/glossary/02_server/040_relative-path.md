# 相対パス

## 正式名称

**Relative Path**

## 一言でいうと

**現在いる場所を基準に目的地を指定するパス**

## 初心者向け説明

現在いるディレクトリの下にDocumentsがあるなら「Documents」と指定できます。「.」は現在のディレクトリ、「..」は一つ上のディレクトリを表します。

## ポイント

- 現在いる場所を基準に目的地を指定するパス
- 現在いるディレクトリの下にDocumentsがあるなら「Documents」と指定できます。「.」は現在のディレクトリ、「..」は一つ上のディレクトリを表します。
