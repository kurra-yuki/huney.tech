# TCP/IP

## 正式名称

**TCP/IP Protocol Suite**

## 一言でいうと

**インターネット通信を支えるプロトコル群**

## 初心者向け説明

TCPやIPを中心に、インターネットなどで利用されるさまざまな通信プロトコルをまとめた呼び方です。TCPとIPだけを意味するわけではありません。

## ポイント

- 「TCP/IP」はネットワーク分野で使われる重要な用語
- まずは「インターネット通信を支えるプロトコル群」と覚えればOK
- 詳しい仕組みは関連記事で段階的に学べる
