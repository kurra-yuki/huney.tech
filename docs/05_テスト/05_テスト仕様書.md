# 1. 本書の目的

本書は、Huney WebサイトのMVPについて、要件定義・基本設計・詳細設計どおりに動作することを確認するためのテスト項目を定義する。

主な確認対象は以下とする。

- 画面表示
- ナビゲーション
- 記事
- 用語辞典
- 動画
- 検索
- カテゴリ
- おすすめ記事
- MDXコンテンツ管理
- レスポンシブ
- SEO
- エラー処理
- アクセシビリティ
- 基本的なパフォーマンス
- 公開フロー

---

# 2. テスト方針

HuneyではMVPとして以下を重視する。

1. 記事を問題なく公開できる
2. 初心者が読みやすい
3. スマートフォンでも利用できる
4. 画像・動画がなくても壊れない
5. 下書きが公開されない
6. SEO基本設定が反映される
7. 存在しないページが適切に404となる

細かな見た目の差異よりも、利用者が正常にコンテンツを閲覧できることを優先する。

- OGPフォールバック動作
- 秘密情報が公開されていない

# 48. リリース判定

以下の重大障害が残っている場合は本番リリースしない。

## Critical

- huney.ukが表示できない
- 記事が閲覧できない
- draft記事が公開される
- HTTPSが利用できない
- 秘密情報が公開される

## High

- スマートフォンで記事が読めない
- 記事リンクが大量に404
- 用語辞典が利用できない
- 本番ページにnoindexが付く
- sitemapに公開記事が含まれない

## Medium / Low

軽微なデザイン崩れ等は内容を確認し、MVPリリース後の修正を許容する。
